Lloyd LR 10K – Strekktest

LR 10K Control Software · tallene 1–8 = trinn i programvarens Quick start
Full veiledning på norsk: skann QR-koden eller gå til ravo10.github.io/USN-kongsberg-lab-mech.
SIKKERHET
• Hendene unna klemmene når traversen går
• Kjenn maskinens stoppknapp (F1 krever PC)
• Vernebriller: prøver kan ryke voldsomt
• Avlast (F5) før du tar ut prøven

A. Koble til og still inn

1–2
  1. Maskinen på, seriekabelen i, start LR 10K Control Software.
  2. PC Config. → COM-port → Connect PC. Status vises til høyre i menylinjen.
  3. Settings: strekk, test- og kjørehastighet, tykkelse, bredde, L0, enheter, lastgrense → Apply to LR 10K.
  4. File → Specify Storage Folder (der testene lagres).

B. Spenn fast og nullstill

3
  1. Kjør traversen med F2 / F3 (hold F4 for fort) til prøven sitter i begge klemmene uten last.
  2. Set zero point F6. Uten test stopper traversen ved 50 N.

C. Optisk ekstensometer

4a–4d
• To grønne Ø5 mm prikker, 60 mm fra hverandre (plasseringsmal), limt flatt på senterlinjen.
• View → Extensometer, kamera på. Pick from image → klikk midt på en prikk.
• L0 = målt avstand mellom prikkene. Tracking: 2 markers.
• Jevnt lys, ingen refleksjoner. Ikke rør kameraet eller holderen under testen.
• Mistes prikkene i 0,5 s, settes testen på pause.

D. Kjør testen

5
  1. Start Test F7. Følg med på prøven, ikke bare skjermen.
  2. Etter brudd: End Test F8. Testen stopper også selv ved lastgrensen.

E. Resultater og avslutning

6–8
  1. Sjekk de automatiske punktene: UTS, grensene for E-modul, Rp0,2. Ctrl+klikk for å flytte eller legge til.
  2. Calculator → beregn, for å se grafen for sann spenning.
  3. Lagre Ctrl+S: .lr10k (kan åpnes igjen) + Excel-bok.
  4. Return to zero point F5, ta ut prøven. + New Test for neste.
